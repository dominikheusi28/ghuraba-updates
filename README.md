# Ghuraba Android-Updates

Dieses öffentliche Repository enthält ausschließlich signierte Android-APKs, Prüfsummen und Versionshinweise. Der Quellcode von Ghuraba bleibt in einem privaten Repository. Persönliche Journal-Einträge und Kontodaten werden hier nicht gespeichert.

Neue Versionen werden nach erfolgreichen Tests und Signaturprüfung automatisch aus dem privaten Build hierher übertragen. Die App liest den [neuesten Release](https://github.com/dominikheusi28/ghuraba-updates/releases/latest) und kann einen Download anbieten. Android verlangt beim Installieren eines APK-Updates weiterhin eine Bestätigung.

Die Dateien unter `delivery/` dienen als Transport für den neuesten Build. Prüfsumme und Signatur werden vor dem öffentlichen Release erneut geprüft.
